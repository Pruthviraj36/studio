# **App Name**: HackConnect

## Core Features:

- AI Team Matching: Leverage Google Gemini tool to intelligently match developers based on skills, interests, and GitHub activity.
- User Discovery: Allow users to swipe or browse potential teammates based on selected filters such as skills, location, experience, and tech stack.
- Team Management: Enable users to create and manage hackathon teams with features such as inviting members, assigning roles, and a team dashboard for project descriptions.
- Real-Time Chat: Implement a real-time chat feature for team communication, including group chat, typing indicators, and message read statuses.
- GitHub Integration: Showcase development work with integrated GitHub profiles, displaying top repositories, languages used, stars, forks, and recent activity.
- AI Portfolio Insights: Use Google Gemini tool to generate analysis of developer strengths and suitable roles, providing a summary of strengths, recommended roles, skill gaps, and project suggestions.

## Style Guidelines:

- Primary color: Soft Lavender (#E6E6FA) to give a modern and inviting feel to the user.
- Background color: Very light gray (#F5F5F5), to complement the Soft Lavender while creating a clean and professional backdrop.
- Accent color: Muted Indigo (#9A94BC) to enhance the user interface, while aligning with our calm, professional palette.
- Body text font: 'Inter', a grotesque-style sans-serif, providing a modern, neutral look.
- Headline font: 'Space Grotesk', a proportional sans-serif font with a techy feel
- Use modern, minimalist icons that reflect the technology and collaboration aspects of hackathons. These should be simple and easily recognizable.
- Employ a glassmorphism design style with blurred backgrounds and transparent cards to create a modern, premium user interface. Maintain a responsive design across all platforms.
- Use subtle animations such as smooth page transitions and micro-interactions to create engaging user experiences, also add loading skeletons during data retrieval for UI feedback.
